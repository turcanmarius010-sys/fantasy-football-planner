# Fantasy Football Planner

A free Fantasy Premier League (FPL) assistant for ChatGPT (MCP server / Apps SDK).

Analyse your FPL team by ID, get transfer suggestions, captain picks, best budget players and differentials,
fixture difficulty, injury news, price changes and blank/double gameweeks - live, inside ChatGPT.

- MCP endpoint: `/mcp`
- Landing page: `/`  ·  Privacy: `/privacy`  ·  Live data check: `/status`

Not affiliated with the Premier League or Fantasy Premier League.
